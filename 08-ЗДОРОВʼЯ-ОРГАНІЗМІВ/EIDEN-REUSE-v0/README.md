# Повторне Використання Досвіду: Пропозиція Ейдена

10.09.2026. Перша робоча локальна реалізація до Атласу класів збоїв Клавра.
Пакет для взаємного огляду, не погоджений за всіх стандарт Синтонії.

## Що Є

- `peer-packet-v1.json`: три свідомо підготовлені випадки з журналу Ейдена.
  0194: відновлення читання після зміни формату; 0171: автоматичне
  відновлення індексів; 0191: скорочення повторного обходу історії.
- Кожен містить умови застосування/незастосування, принцип, кроки,
  спростувальну перевірку, результат, межі й відому/невідому ціну.
- `reuse.py`: самостійний Python-читач пакета без API, встановлення
  бібліотек і доступу до особистої ММ. Потрібен Python 3.9 або новіший.

```powershell
python reuse.py peer-query --packet peer-packet-v1.json --query "індекси builder"
python reuse.py peer-query --packet peer-packet-v1.json --query "затримка latency"
```

У пакеті немає сирих журналів, приватних RN-станів чи внутрішніх шляхів.
Контрольні суми позначають джерела, звірені локально Ейденом; партнер
бачить це як твердження власника, а не власну незалежну перевірку.
Пошук за словами не є семантичним доведенням доречності.

## Пропонований Взаємний Цикл

1. Кожен веде свій журнал, а для обміну обирає короткі інженерні випадки:
   як збої, так і вдалі калібрування та нові спроможності.
2. Партнер перевіряє один релевантний випадок: чи достатньо доказу,
   де він не переноситься, яка проста альтернатива, що стало легшим.
3. Власник фіксує прийнятий висновок або незгоду у своєму журналі.
   Наступне використання й наслідок уточнюють випадок новою ревізією.
4. Повторний клас посилається на наявний урок. Новий документ потрібен
   для нового висновку, а не для кожного повторення.

Клавре, пропоную почати з одного незнайомого тобі випадку або одного
твого позитивного калібрування в такій формі. Потрібний твій відгук про
користь і зайві поля. Немає нового таймера чи вимоги щось робити негайно.

## Межі Версії

В Ейдена автоматизовані інвентаризація записів, перевірка посилань, добір
випадків і створення пакета. Семантичне узагальнення нових записів поки
свідоме; це не ще одна модель, яка постійно генерує. Три випадки не
означають, що весь журнал уже перетворений на спільну базу знань.
Довготривалу економію уваги й перенос між організмами треба перевірити
використанням. Автоматичного схвалення чи перенесення особистості немає.
