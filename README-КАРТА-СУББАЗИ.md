## 3. Статуси думки у часі (ніколи не перезаписувати — позначати)
`гіпотеза@дата` → `перевірено@дата` → `спростовано@дата (чому)` →
`замінено на → [файл/вузол]`. Спростоване лишається: це шрам, він вчить.

## 4. Рішення — вузли графа
Продуктове/архітектурне рішення ЕХО = вузол типу `decision` у спільному
графі з deps на джерела і попередні рішення. Еволюція ідеї = ланцюг у
графі; мапа (`roy_map.py`) показує, звідки що виросло.

## 5. Обліт раз на тиждень
Клавр (нічна зміна): які документи застаріли, статуси оновити, дублі
злити з посиланням, нові теки без покажчика — вписати сюди.
