## Процес дослідницького треку

1. **План** — файл `трек-НАЗВА/PLAN.md`: гіпотеза, метрики-судді (детерміновані!),
   стоп-умова, бюджет. → **ревю Аетрема файлом** `PLAN.РЕВЮ-АЕТРЕМ.md`.
2. **Прогін** — Рій + стенди; всі події у графі (dags/), артефакти в artifacts/.
3. **Знімок** — `python 03-ПРОТОКОЛИ/syntonia_dag.py handoff <dag>` → `трек-НАЗВА/ЗНІМОК-дата.md`
   + жива мапа `roy_map_<dag>.html`.
4. **Валідація** — Аетрем: чи відповідає результат плану, чи чесні межі;
   Клавр: ворота промоції. Розбіжність = дані, пишеться у трек.
5. **Урок** — навіть провальний трек лишає шрами у графі (не стирається).
