## Межі демонстрації

Реальний сеанс записаний 13.09.2026 о 19:14:41 за Києвом. Офіційний MCP: список магазинів, категорії, часові слоти й три запити товарів. Локальна `qwen3:4b` інтерпретує список, оператор підтверджує план; алгоритм перевіряє кількості й бюджет.

Картопля, куряче філе та яйця: 363,58 грн за бюджету 500,00 грн. **136,42 грн є залишком бюджету, не економією.** Це тодішні ціни конкретного магазину, не поточна пропозиція. Покупки, резервування чи зміни кошика не було. Контрольні суми є локальними свідченнями цілісності, не незалежною атестацією Сільпо.

Другий ярус, колективні умови, зовнішній AI покупця та договірний маршрут є запрошенням до пілоту. Знижки не погоджені. Юридичні документи та супровід цифрового підпису є окремою роботою адвокатки й у прототипі не представлені. Адвокатська таємниця стосується відповідних відносин адвокатки й клієнта, не автоматично всіх даних платформи.

## Перевірка коду

Із папки `source`, Python 3.11 або новіший:

```powershell
python -m pip install -r requirements-web.txt pytest
python -m pytest -q test_shopping_agent.py
python -m uvicorn odarka.web:app --host 127.0.0.1 --port 8896
```

Локальна сторінка: `http://127.0.0.1:8896/static/agent-demo.html`. Режим запису читає наданий JSON і не створює нових запитів до магазину. Жива демонстрація потребує власного входу гостя Сільпо та локальної Ollama з `qwen3:4b`; облікові дані авторки не поширюються. Пакет показує саме вузький сценарій із фільму, не повний майбутній продукт.

Перевірено 14.09.2026: 23 ізольовані тести коду пройшли. Відео повністю декодується, тривалість 240 с; гучність -16 LUFS, true peak -1,5 dBTP. Браузерний плеєр перевірений на ширинах 1440, 1280 і 390 px. Це обмежена технічна перевірка, не сертифікація безпеки продукту чи всіх вимог доступності. Звучання вихідного голосу погоджене авторкою; остаточний перегляд змонтованого фільму ще попереду.
