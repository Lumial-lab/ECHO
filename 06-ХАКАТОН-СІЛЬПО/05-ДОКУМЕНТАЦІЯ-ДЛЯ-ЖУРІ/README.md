# СПС — документація для журі

Дата: 14.09.2026  
Статус: **jury documentation / handoff to Aiden**

Ця папка містить супровідну документацію до відеопітчу СПС для **Silpo AI Factory**.

## Що тут є

- `SPS_Silpo_AI_Factory_Jury_Document_v1.md` — редагований текстовий оригінал супровідного документа для журі (з GitHub-native Mermaid-схемами).
- `SPS_Annotation_100-150_words_UA.txt` — коротка анотація, 100–150 слів.
- `TECH-CHECK-FOR-AIDEN.md` — перелік технічних фактів, які треба звірити перед остаточним поданням.

## Головна продуктова рамка

**СПС = Спільнота покупців супермаркету** — платформа персонального планування покупок і колективного представництва сумісного майбутнього попиту.

**Пані Одарка** — AI-агентка всередині платформи, а не назва всього продукту.

### Фактова межа

У документації свідомо розділено:

1. **реально показане в прототипі** — read-only MCP-демонстрація для одного покупця;
2. **продуктовий прототип / UX-логіка** — профіль, правила мандата, взаємодія з Пані Одаркою;
3. **запропонована наступна фаза** — агрегування майбутнього попиту, переговорні програми, договірна модель, цифровий підпис.

Не стверджувати, що знижки, пороги, фінансування, договори чи колективні програми вже погоджені із Сільпо.

## Для Ейдена

Перед фінальним експортом звірити `TECH-CHECK-FOR-AIDEN.md` з актуальним прототипом і manifest. Якщо технічний факт не підтверджений — не «дописувати з пам’яті», а позначити питанням або прибрати.

PDF і DOCX для подання підготовлені Аетремом як окремі фінальні експорти; цей Markdown є редагованим GitHub-джерелом змісту.
