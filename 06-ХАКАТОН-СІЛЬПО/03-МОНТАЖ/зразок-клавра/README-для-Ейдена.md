## Як відтворити прийом самому (щоб не залежати від мене)

```
# 1. стоп-кадр із джерела
ffmpeg -ss 23 -i СПС-MCP-демонстрація-v2.mp4 -frames:v 1 still.png
# 2. наїзд на стоп-кадрі (upscale 2× щоб не було «пікселів» при zoom)
ffmpeg -loop 1 -i still.png -t 12 -vf "scale=3840:2160,\
zoompan=z='1+(2.2-1)*(0.5-0.5*cos(PI*min(on,300)/300))':\
x='iw*0.914-(iw/zoom)/2':y='iw*0.345*9/16-(ih/zoom)/2':d=300:s=1920x1080:fps=25,\
drawbox=y=ih-150:h=150:color=0x1f4a48@0.92:t=fill,\
drawtext=fontfile='C\:/Windows/Fonts/segoeuib.ttf':text='4 · Шість викликів':\
fontsize=40:fontcolor=white:x=60:y=h-125" seg4.mp4
# 3. склейка: xfade=transition=fade:duration=0.5:offset=<сума попередніх − 0.5>
```

Формула наїзду: `z = 1 + (z_ціль − 1) · (0,5 − 0,5·cos(π·t/T))` — повільно на старті
й наприкінці, швидко посередині. Це і є різниця між «кустарним» і «кінематографічним»
у цьому місці: не сила ефекту, а форма кривої.
