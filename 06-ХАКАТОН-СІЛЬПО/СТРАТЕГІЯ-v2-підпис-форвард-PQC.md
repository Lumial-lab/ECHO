## Ядро подачі (вузьке): ПІДПИС СПОЖИВАЧА + МАНДАТ ДЛЯ AI-ДОРУЧЕНЬ
Проблема: AI-агенту не можна юридично довіряти покупки; люди бояться;
разові замовлення — стеля нинішнього е-комерсу.
Рішення: рамковий договір приєднання (Сільпо↔Гість, раз через Дію/КЕП;
сторони визнають УЕП покупця — законна конструкція, пише Люміаль) →
далі кожна дія агента = підписаний МАНДАТ з межами (бюджет/період/категорії).

## Три опори цінності
1. **Форвард для родини**: сезонні/тривалі замовлення за фіксованою ціною.
   Сільпо: прогноз попиту, закупівлі, логістика, кешфлоу. Гість: захист від
   інфляції, бюджетування. Формула пітчу: «інструменти планування, які досі
   мали лише корпорації — тепер у родини».
2. **Безпека на роки**: гібридний підпис Ed25519 + ML-DSA (постквантовий,
   NIST FIPS 204) — довготривалий договір вимагає підпису, що переживе
   квантову еру. Слайд «підпис для постквантової ери».
3. **Захист обох напрямків**: мандат захищає людину ВІД агента (межі =
   Authority Envelope); підпис захищає агента ВІД підробки (кожна дія
   Примхи підписана й атрибутована; журнал append-only = доказовість).
Юридичний блок: ВИЗНАЧЕНІСТЬ + БЕЗПЕКА (слова Люміаль).

## MVP-демо (показуємо ОДНЕ, end-to-end)
профіль-примхи (локально, дані належать Гостю) → мандат підписується
(гібрид; рамковий — демо-Дія) → сезонне замовлення за фіксованою ціною
через MCP Сільпо (реальні tools у кадрі!) → верифікація підпису на боці
магазину → Примха-рівень-1: стежить і повідомляє.
Все інше (рівні проактивності, скарги/заяви, повна методологія CPI) —
фінальний слайд «куди росте» + ОКРЕМИЙ продукт «Пані Примха» потім.
