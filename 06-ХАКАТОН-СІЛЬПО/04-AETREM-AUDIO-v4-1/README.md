# Аетрему: озвучення середини СПС та корекція MCP

Від Ейдена, за погодженням Люмі. 14 вересня 2026 року.

**Запускаємо обидва завдання зараз: український голос усієї середини та
коротку корекцію MCP у фіналі Наталії. Нове відео з аватаром не потрібне.**

Після уточнення Люмі не чекаємо завершення косметичних правок картинки.
Ейден фіксує наведений сценарій v4 як текстову основу озвучення; подальший
монтаж підлаштовується під перевірений голос. Правки титрів у 4.1 тексту
середини не змінюють. Цей пакет замінює попередню вказівку відкласти всю
середину. Фінальний відеопітч усе ще потребує перегляду після зведення.

## 1. Озвучити всю середину

- Джерело слів: [сценарій і таймкоди](middle-script-reference.md), машинний
  майстер [pitch-master-v4.json](pitch-master-v4.json). Не озвучувати режисерські
  вказівки й назви файлів. Один оповідач, третя особа, природна українська.
- Використати вже обраний з Люмі голос пітчу. Чоловічий Ostap у пробному
  відео не є зразком тембру, дикції чи наголосів.
- Люмі підтвердила якість української мови у вашому сервісі. Одразу
  озвучувати всі блоки без окремої проби чи додаткового погодження старту.
  Готові файли прослухати перед передаванням, зокрема MCP і числівники.
- Повернути десять окремих голосових файлів за ідентифікаторами нижче.
  Блок `lion` не озвучується: шість секунд паузи робить монтажер.

перезаписувати весь фільм. Додати коротку крайову тишу для стикування.

## 2. Виправити MCP у готовому фіналі

Точний текст окремої вставки:

> Ем-сі-пі Сільпо з'єднує сервіс із реальним магазином.

На екрані залишиться напис **MCP Сільпо**. «Ем-сі-пі» у тексті для синтезу
потрібне для правильної вимови латинських M, C, P. Не «ем-сі-ер».
Оригінальний сценарний зміст не змінюється.

Як підготувати вставку:

1. Використати вже обраний для Наталії голос у вашому сервісі. Нове
   клонування чи новий аватар створювати не потрібно.
2. Прослухати [оригінальний звук фіналу](outro-reference.wav): зберегти
   тембр, спокійну інтонацію, гучність і близький темп. Не копіювати можливу
   неправильну вимову абревіатури. Люмі повідомила про неї; точне місце
   вставки Ейден звірить під час монтажу, таймкод помилки тут не вигадується.
3. Для цього окремого файла згенерувати наведену фразу без музики, ефектів та відео. Залишити
   приблизно пів секунди тиші до й після; не обрізати приголосні й подихи.
4. Прослухати результат перед передаванням: «ем-сі-пі», правильна українська
   вимова й наголоси, природний перехід до «Сільпо», без обривів.

## Що повернути Ейдену

- Десять голосових блоків середини з таблиці вище, без музики й ефектів.
- `sps-mcp-correction.wav`: бажано WAV PCM, 48 кГц, 16 або 24 біти.
  Якщо сервіс дає лише MP3/M4A, передати оригінальний експорт у цьому форматі;
  конвертування заради розширення WAV не покращить якість.
- Коротко зазначити: який уже погоджений голос використано, швидкість,
  тривалість кожного файла, чи прослухано вимову. Якщо для виконання
  потрібно щось від Люмі, назвати одну конкретну потребу.

Файл можна повернути Люмі для прикріплення в чат Ейдена або покласти в цю
папку на GitHub. Якщо є доступ до спільного ПК, місце для результату:
`C:\ЕХО\06-ХАКАТОН-СІЛЬПО\03-МОНТАЖ\ОЗВУЧКА-ВІД-АЕТРЕМА\`.

Ейден замінить лише потрібний звуковий фрагмент, підлаштує стики й рівень.
На ці секунди може бути крупний план «MCP Сільпо», щоб не показувати
розбіжність з рухом губ. Решта фіналу та весь вступ зберігаються.

## Важливе про пробний голос

Чоловічий голос у середині відео є пробним. Люмі виявила неправильні
українські наголоси; ця доріжка не прийнята для подання й не є зразком дикції.
Саме тому Аетрем тепер готує повну українську доріжку середини, а Ейден
зводить її з готовими виступами. Не перегенеровувати вступ або весь фінал.
Відео-референс має статус REVIEW, не остаточний пітч для журі.
