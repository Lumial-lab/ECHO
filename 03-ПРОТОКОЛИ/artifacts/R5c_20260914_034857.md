### КРОК 0 — РАМКА (Frame Shift)
Проблема сформульована коректно, але варто уточнити, що "хардкодовані напрямки (±4,±4,0^22)" — це **неоптимальний евристичний вибір**, який не враховує анізотропію даних (домінування PC1). Це призводить до:
1. **Губи** (miscluster) — через невідповідність між розподілом даних і фіксованими напрямками.
2. **Нерівномірного розподілу** (29% фрагментів у 10 комірках) — через те, що деякі напрямки "ловить" основну масу даних, інші залишаються практично порожніми.

Сильніша система координат — **адаптивні напрямки**, що враховують:
- Коваріаційну матрицю даних (наприклад, через Mahalanobis-відстань).
- Ієрархічну структуру (як у S5b).

### КРОК 2 — РЕЗУЛЬТАТ
**1) Відповідь по суті:**
- Проблема в **нерівномірній чуйності** ґратки до анізотропії даних. Фіксовані напрямки "не влучають" в основні скупчення.
- Альтернативи (в порядку зростання CPU-вартості):
  - **Ієрархічне квантування** (S5b): поділ на групи + підгрупи.
  - **k-means (4096 центроїдів)**: адаптивні кластери, але потребує періодичного перетренування.
  - **Вектори Ліча**: теоретично ідеально, але непрактично через обчислювальну складність.

**2) Хід міркування:**
- Miscluster=0.9 означає, що 90% фрагментів попадають у сусідні комірки при малих збуреннях — це артефакт "розтягнутої" PCA-проекції.
- **Ієрархія** краща через локальну адаптацію (менше залежить від глобальної анізотропії).

**3) Емпірична перевірка:**
```python
# Псевдокод для стенду R5c
import numpy as np
from sklearn.cluster import MiniBatchKMeans

# Тестові дані з R5b (24D проекції)

# 1. k-means варіант

kmeans.fit(X)
labels = kmeans.predict(X)

# 2. Оцінка зсуву метрик vs R5b
from sklearn.metrics import pairwise_distances_argmin_min
grid_directions = load_grid()  # 1104 фіксованих напрямків
grid_labels = pairwise_distances_argmin_min(X, grid_directions)[0]

# Порівняти:
# - np.unique(labels).shape[0] (число реально використаних кластерів)
# - Джині-індекс розподілу кластерів
# - N_r@10 на оригінальних вкладеннях vs квантованих
```

**4) Межі й ризики:**
- **k-means**: чутливий до ініціалізації, може давати "вакантні" кластери.
- **Ліч**: непрактично для реального використання (196560 косинусів на вектор).
- **Ієрархія**: додаткові hyperparameter (глибина дерева, балансування).

**5) Сценарії збою:**
- Якщо дані **швидко дрейфують** (S6), k-means буде вимагати частих перетренувань — вартість перевищить виграш.
- Якщо **дисперсія PCA рівномірна**, фіксована ґратка може виявитися достатньою.
