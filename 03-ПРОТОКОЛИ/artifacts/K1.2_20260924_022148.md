**3) Емпірична перевірка**:

**4) Ризики/межі**:

- Gumroad не надає даних про попит без акаунта продавця (B1.1).  
- **Не вистачає**: конкретного числа днів для правила "0 продажів" (але це заборонено вигадувати).  

**5) Сценарії збою**:

- Refund Policy не відкрита (K5.3 не виконано).  
- Дані продажів не надходять через помилку API Gumroad.
