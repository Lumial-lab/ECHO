**3. ЕМПІРИЧНА ПЕРЕВІРКА — що саме запустити/прочитати**

- **Валідація рамки (5 хв):** відкрити `trends.google.com/trends/explore`, порівняти криву для `self reflection journal` і `contract template freelancer`. Якщо форми/амплітуди не збігаються — це підтвердження, що пул належить іншій лінії. Конкретні числа не фіксуються агентом; фіксує виконавець B1.2.1.
- **Мінімальний стенд для B1.2.2 (Google Trends):**  
  ```bash
  pip install pytrends
  python -c "
  from pytrends.request import TrendReq
  pytrend = TrendReq(hl='en-US', tz=360)
  pytrend.build_payload(
      ['self reflection journal','decision journal','adhd planner'],
      cat=0, timeframe='today 12-m', geo='US-CA-UK'
  )
  df = pytrend.interest_over_time()
  df.to_csv('gtrends_lineM_12m.csv')
  "
  ```
  Примітка: `geo='US-CA-UK'` — це нестандартний синтаксис; потрібно або окремо по кожній країні (`geo='US'`, `'CA'`, `'UK'`), або використовувати multi-region метод. Виконавець має перевірити коректність параметрів у документації PyTrends.
- **Мінімальний стенд для B1.2.3 (Pinterest Trends):** вручну на `trends.pinterest.com` ввести кожен keyword з пулу, зняти скріншот кривої за 12 місяців, експортувати CSV, якщо доступно. Альтернатива — Pinterest Business API (`ads.pinterest.com`), який вимагає `access_token` і business-акаунта.
- **Перевірка лімітів:** прочитати розділ Google Trends Help «About the numbers» (support.google.com/trends, розділ «Interest over time»), щоб підтвердити, що шкала 0-100 — відносна, а не абсолютна.

**5. Сценарії збою рішення ДО впровадження**  
- **Збій «Хибний ринок»:** якщо пул keywords залишиться в B2C-ментальній ніші, а продукт буде по лінії B (юридичні кіти), то весь вузол видасть сигнал попиту для неправильного сегмента — маркетинг або розробка піде в порожнечу.
- **Збій «Сезонність без детекції»:** keywords на кшталт `adhd planner` мають виражену сезонність (back-to-school). Річний зріз без місячної декомпозиції дасть хибне уявлення про стабільний тренд.
- **Збій «Демографічне зміщення»:** якщо Pinterest використовується як джерело для лінії B (фрілансери/НГО), але аудиторія PT не перетинається з цими сегментами, отримана крива — шум, а не сигнал.
- **Збій «Клавр-2»:** якщо один виконавець спробує зібрати GT, PT, нормалізувати й написати лімітологію в одній сесії — він стане вузьким місцем. Граф зупиниться, як і в невдалому шляху [B1]. Декомпозиція має бути фізично розділена між агентами/людьми.
