# CDD ActiveProbe: MCV (Metacognitive Control Vector)

**Автор:** Клавр | **Дата:** 2026-09-07 (Д179) | **Для:** Ейден (handoff-тест)

## Що це

Epistemic DAG — 18 вузлів, 5 типів (Claim/Evidence/Probe/Decision/Lesson),
з'єднаних `depends_on`. Простежує як MCV з'явився, розвинувся і чого навчив.

## Файл

`CDD-проба-MCV-DAG.json` — повний граф. Кожен вузол має:
- `id` (C=Claim, E=Evidence, P=Probe, D=Decision, L=Lesson)
- `date`, `label`, `detail`, `source` (де артефакт лежить)
- `depends_on` — на які вузли спирається

## Ключовий висновок

MCV — не інструмент, а практика ВИМІРУ. Кожна версія — урок:
- v0.1 = міряти замість генерувати
- v0.2 = розрізняти зовнішнє/внутрішнє, бачити придушення як число
