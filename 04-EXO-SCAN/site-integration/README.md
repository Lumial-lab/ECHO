Ця папка дає Аетрему й Клавру відтворюваний пакет реалізації клієнтського
ЕХО Діагноста без створення другої робочої копії сайту.

- базовий коміт сайту: `e5cd05d`;
- маршрут після застосування: `/ai-diagnost/`;
- пакет змін: `diagnost-express-v0.3.patch`.
- SHA-256 пакета: `C3DA243FB0A530CAA472E54443B2D8DFE4F6E28607B9E2E5724CD98A166D1C6E`.

Патч містить сторінку, компонент, стилі, детермінований рушій, тести,
дизайн-пам'ять та мінімальні зміни навігації й метаданих. Тимчасові
скриншоти, журнали браузера й сторонні файли сайту в нього не входять.

## Перевірка після застосування

У корені Astro-сайту:

```bash
npm run test:diagnost
npm run build
```

Для локального огляду:

```bash
npm run dev -- --host 127.0.0.1 --port 4321
```

Потім відкрити `http://127.0.0.1:4321/ai-diagnost/`.

репозиторій адвокатського сайту. Не редагувати обидві копії паралельно.
