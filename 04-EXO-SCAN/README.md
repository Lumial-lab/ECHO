## Чого тут НЕМАЄ (і чому)

**Публічного інтерфейсу, зберігання сесій, серверної заявки та деплою.**
Поточний прохід розглядає один пріоритетний процес. Галузеві приклади є,
але галузеві поглиблення, другий процес і повний паспорт ще не реалізовані.
Пробні ваги треба калібрувати з Люміаль та Аетремом і перевіряти інтерв'ю.

## Як це працює простими словами

1. Каталог `questions.json` містить:
   - текст питання українською
   - варіанти відповідей
   - яка відповідь на яку вісь впливає і наскільки
   - за якої умови показувати питання (розгалуження)

2. Майбутній інтерфейс покаже доречні питання без наперед обраних відповідей.
   Час проходження ще не виміряний. Контрольні маршрути мають 21-23 питання.

3. Рушій рахує:
   - **8 осей радару** (бали 0-4, або ⚪ якщо мало відповідей)
   - **Рівень даних обраного процесу** (D0-D4 або UNKNOWN, не рейтинг усієї компанії)
   - **Теги рекомендацій** (наприклад: «спочатку потрібна базова цифровізація»)

4. Зараз результат доступний локально через `first_pass.py`; показ на сайті ще не реалізовано.

## Типи питань

- **single_choice** — один варіант з кількох (найчастіший)
- **multi_choice** — кілька варіантів (напр. «які системи використовуєте»)
- **scale** — числова шкала
- **number** — точне число (напр. «скільки людей у відділі»)
- **text** — відкрита відповідь (мінімум таких — для безпеки)

## Правила з брифу, вшиті в рушій

1. **D0-D1 → спочатку базова цифровізація.** Якщо підприємство на рівні
   «папір» або «скани» — рушій автоматично додає тег
   `DIGITAL_FOUNDATION_REQUIRED`. Повний EXO тут передчасний, але шлях
   до нього починається саме тут (дорожня карта, не відмова).

2. **Однакові відповіді = однаковий результат.** Завжди. Це не ШІ-фантазія,
   а прозорий розрахунок.

3. **Недостатньо відповідей на вісь → ⚪.** Чесне «не знаємо» замість
   вигаданого балу. Радар з двома ⚪ викликає більше довіри, ніж вісім
   намальованих цифр.

4. **Версія методики в кожному результаті.** Щоб повторний скан через
   3 місяці був порівнянним.

5. **Часткове проходження можна оцінити.** Збереження сесії ще не реалізовано.
   Пропущене, невідоме й незастосовне не занижують оцінку.

6. **Власні уточнення** передаються окремим словником `_comments` за ID питання.
   Вони є темами для консультації, не оцінюються довільно й не вимагають контакту.
   Приховані гілки та їхні уточнення не впливають на поточний результат.

## Локальний Запуск

Перевірено на Python 3.13. Розрахунок використовує лише стандартну бібліотеку:
із папки `04-EXO-SCAN` запустити приклад нижче. Дані не надсилаються назовні.

```bash
python -B -X utf8 first_pass.py examples/small_digital.json
```

Для тестів потрібні `pytest` і `jsonschema`, версії зафіксовані в
`requirements-dev.txt`. Бажано встановлювати їх в окреме віртуальне середовище.

```bash
python -m pip install -r requirements-dev.txt
python -B -X utf8 -m pytest -q test_scoring.py test_first_pass.py
```

Локальний профіль SYNTONIA використовує встановлений стенд Синтонії.
Для звичайного відтворення 43 тестів він не потрібен. Сирі журнали стенду,
кеші, реальні анкети клієнтів і секрети в цей розділ не публікуємо.
