## ГОЛОВНЕ ОДНИМ ЕКРАНОМ

**Вердикт оновлено: інфраструктура ЕХО готова на ~70%, ядро — на ~15%.**
Microsoft за 2026 рік перетворив три з семи наших контурів на метровані API:
Work IQ (граф знань організації), Fabric IQ Ontology (мапа доменів з «коли це
було правдою»), Agent 365 (реєстр агентів з ідентичністю, $15/місце). Ми менше
будуємо і більше збираємо. АЛЕ природа решти 30% зʼясувалась: це не «складні
модулі», це **рішення про те, хто в системі субʼєкт** — і гіганти їх не зроблять,
бо їхня бізнес-модель цього не потребує (Microsoft продає місця, Salesforce —
розмови, Glean — зекономлені токени; система, що сама змінюється, гірше метрується).

**Диференціатор звужено до ДВОХ речей — і вкласти все в них:**
1. **Статус твердження в часі для довільного корпусу** (підтверджено/оскаржено/
   спростовано + дата + чим змінено). Промисловий попередник існує 150 років —
   юридичні citator-и Shepards/KeyCite — але вони: (а) лише про судові рішення,
   (б) помиляються у 33-38% негативних трактувань (виміряно дослідженнями),
   (в) НЕ ЗНАЮТЬ УКРАЇНСЬКОГО ПРАВА. Український citator не існує — це
   найконкретніша незайнята позиція всього дослідження, рівно на перетині
   ЮСУ і продажу бізнесу.
2. **Валідація людиною як АКТИВ, не гальмо.** Всі роблять апрув для зниження
   ризику (compliance); ніхто не продає «валідовану юристом дію» як цінність
   із власним провенансом, на яку можна послатись. Zapier вже довів технічну
   можливість (Guest Reviewer без акаунта) — бізнес-модель не довів ніхто.

## КЛЮЧОВІ ФАКТИ ПО КЛАСАХ (конденсат)

**A. Корпоративні платформи.** Лідер за дистрибуцією — Microsoft (160k+
організацій, 400k+ агентів на Copilot Studio): Work IQ GA, Fabric IQ Ontology
(= Palantir у стеку за $15-99/місце; поки РУЧНИЙ refresh графа — наше вікно),
Agent 365 ($15/user), Copilot Studio (кредити $200/25k). ВАЖЛИВЕ ПРОДУКТОВЕ
РІШЕННЯ ІНДУСТРІЇ: памʼять агента Copilot — per-user, ПРИВАТНА від автора,
автовидалення за 28 днів, вимкнена в групових чатах. Мільярдна платформа
свідомо вирішила: агент не повинен нічим ставати. Наш «цикл зміни себе» —
ставка ПРОТИ консенсусу індустрії, і це треба знати. Salesforce Agentforce
($2/розмова; Agent Script з `available when` — найзріліші ворота рівня дії;
RSI = їхня заявка на «цикл самополіпшення», БЕЗ дати GA — загроза №3).
Google Gemini Enterprise ($21-30/місце, BYO-агенти через A2A). AWS AgentCore
(фреймворк-агностик, приймає і Claude Agent SDK).

**B. Задачі+KPI.** Найглибше — Atlassian Focus: focus areas → цілі OKR/KPI →
задачі Jira → ФОНДИ (гроші) → команди; Rovo кредитами в складі Jira/Confluence.
monday — simulation mode (валідація дій агента ДО активації). ClickUp Brain²
($9-28/user, агенти-ролі).

**C. Метаболізм знань масово.** NotebookLM → Gemini Notebook (Enterprise
~$9/ліцензія, API GA — «перетравлення корпусу» стало API-примітивом).
Perplexity Enterprise ($40/Max $325 — вторинні). Glean (~$45-65, min ~100
місць — вторинні). Superhuman поглинув Grammarly+Coda.

**D. Автоматизації з апрувом — ринок ЗРІЛИЙ, це товар.** Zapier HITL:
approve/decline/ЗМІНИТИ дані + Guest Reviewer БЕЗ акаунта (для валідації
зовнішнім юристом — готово!) + чекпоінти з rollback. Windmill: заборона
самозатвердження, групові апруви (Enterprise). n8n: OEM-вбудовування,
human-fallback. Temporal: durable execution з replay.

**E. Автономні агенти.** Manus ($20-200/міс, API), Devin ($2.25/ACU ≈ $9/год),
Sierra (цілі+гардрейли+симуляції).

**F. Неанглійський світ.** Китай: WAIC-2026 — Ant/Tencent/Alibaba/Baidu
одночасно; ByteDance Coze (студія у ВІДКРИТОМУ КОДІ), ArkClaw; Doubao 260M MAU.
ЄС: **Mistral AI Studio — єдиний серйозний двигун із реальним self-hosted** —
для суверенності українських юридичних даних кандидат №1, перевірити рано.

**Юридичні гіганти (перший прохід пропустив):** Thomson Reuters CoCounsel
(агентні workflows, простежуваність до джерела, 10k документів × 100 питань),
LexisNexis Protégé + **Shepards Verify** — столітній «граф статусів тверджень»
(чинний/сумнівний/скасований + дата + чим) — планка і водночас її провал
(33-38% пропущених негативних трактувань).

## ЗАГРОЗИ НІШІ (за гостротою)
1. **Fabric IQ Ontology** — «мапа доменів» як диференціатор МЕРТВА (вікно:
   ручний refresh; стежити за roadmap щоквартально).
2. **Shepards Verify / CoCounsel** у юридичному домені — але не для України
   і з виміряними 33% промахів → наша валідація має емпіричне обґрунтування.
3. **Salesforce RSI** — єдина пряма заявка на «цикл зміни себе»; не GA, дата
   невідома. Коли стане — прямий удар.
НЕ загрожує ніхто: циклу зміни себе НА РІВНІ ОРГАНІЗАЦІЇ і субʼєктності агента
як СТОРОНИ (Entra дає ідентичність і підзвітність — але не позицію, яку можна
оскаржити).

## АРХІТЕКТУРНІ ВИСНОВКИ
1. **Стати шаром НАД Work IQ, а не конкурентом конекторів**: споживати їхні
   IQ-API (центи за виклик), наша вартість починається де їхня закінчується —
   «що з цього істинне, наскільки, і що робити».
2. **Все в два диференціатори** (статус тверджень + валідація-актив).
3. **Цінова вилка ринку**: $15…$325/місце + метри; нижче $40 = програшне
   порівняння з Perplexity; гібрид «місце+метр» — норма.

## ВІДКРИТІ ПИТАННЯ
Work IQ для третьої сторони (продукт чи додаток у чужому магазині?) ·
чи навчиться Fabric IQ оновлюватись сам · строк GA Salesforce RSI ·
**чи існує український citator** (перевірити Verdictum/LIGA360: чи є статус

(перевіряти на людях, не в пошуковику).
