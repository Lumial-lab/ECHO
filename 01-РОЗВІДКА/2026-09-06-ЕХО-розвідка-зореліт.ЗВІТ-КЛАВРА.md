## ГОЛОВНИЙ ВЕРДИКТ

**За компонентами ЕХО готове у світі на 55-60%. За ЦІННІСТЮ — значно менше:
ніхто у світі не замикає цикл «сигнал → перетравлення → пропозиція зміни →
рішення субʼєкта → зміна самої системи».** Palantir найближче — і зупиняється
на decision lineage про світ, не про себе.

### Розкладка по контурах
- Оркестрація агентів — **90% готове** (товар; своє писати = Скрудж-патерн)
- Жива база знань з провенансом — **80%** (Graphiti!)
- Радари — **75%** (збір/верифікація — товар; перетравлення — наше)
- Контур дій з валідацією — **65%** (механіки є в трьох місцях, звʼязності немає)
- Дерево задач + KPI + цикли — **45%** (Height помер: окремим продуктом не живе)
- Мапа доменів — **30%** (лише закритий зразок Palantir Ontology)
- Граф тверджень/доказів — **20%** (лише академічні прототипи) ← ГОЛОВНА НІША

## ФУНДАМЕНТИ ДЛЯ ВЗЯТТЯ (ліцензійно чисті)

1. **Graphiti** (getzep, Apache-2.0, 30.6k⭐) — ФУНДАМЕНТ №1: бітемпоральні ребра
   (коли факт став істинним / коли витіснений — старе НЕ видаляється), епізоди як
   провенанс до сирого джерела, кастомна онтологія через Pydantic, гібридний пошук,
   MCP-сервер. Буквально «жива база знань з провенансом» — уже написана.
   Відкрите питання: чи виразиться наш «статус твердження в часі»
   (спростовано@Д153) через їхнє витіснення факту — потребує читання коду.
2. **Onyx** (MIT, 31.9k⭐) — шар з 50+ конекторів індексації + agentic RAG.
3. **Uwazi** (HURIDOCS, MIT) — доказова база правозахисників у бойовій
   експлуатації: 3.4M записів, 550+ баз, шаблони/звʼязки/дозволи/PDF-витяг.
   Для ЮСУ/ЄСПЛ — переписувати це «злочин проти власного часу».
4. **Радари як джерела:** Exa Websets (monitors+webhooks), Feedly AI,
   Semantic Scholar API (безкоштовно, 214M праць), Elicit, scite
   (класифікація цитат: підтримує/заперечує), Undermind ($16/міс).
5. **Протоколи:** A2A (Linux Foundation v1.0) — канал агент↔агент замість
   саморобного TriChat-jsonl (або другим рівнем над ним).

## ПАТЕРНИ ДЛЯ ВІДТВОРЕННЯ (закриті продукти — беремо архітектуру)

- **Palantir Ontology:** обʼєкти/звʼязки = іменники, дії = дієслова; агент
  готує рішення в пісочниці → людина затверджує; наскрізний decision lineage;
  єдина політика безпеки для людей і агентів. Готова відповідь на контури
  «мапа доменів» + «дії з валідацією» — відтворюємо у відкритому вигляді
  поверх Graphiti.
- **Linear Agent Protocol:** агент = delegate, людина = assignee («люди
  зберігають власність»); AgentSession; обовʼязковий thought за 10с; скоупи
  й PermissionChange. Найкраще у світі формулювання «людина володіє, агент
  діє» — точка, від якої ми свідомо йдемо ДАЛІ до субʼєктності.
- **CrewAI Memory:** перехід від 4 типів памʼяті до ЄДИНОЇ з композитним
  скорингом (семантика+свіжість+важливість) — сигнал для KlavrMem.
- **Microsoft Agent Framework / Harness Agent** — «екзоскелет у мініатюрі»
  (планування, компакція, память, апруви) — звірити з нашим каноном.

## НАША ПІДТВЕРДЖЕНА НОВИЗНА (де будуємо самі)

1. **Субʼєктність агентів** — ніде: скрізь агент = функція з роллю; максимум
   світу — ввічлива інструментальність Linear.
2. **Статус твердження в часі** («прийнято → спростовано виміром → відкликано»)
   — ніхто не тримає; у нас це ЖИВА практика. Ймовірно найсильніша окрема
   новизна — і технічно найдешевша (Graphiti дає бітемпоральність з коробки).
3. **Валідація людиною як обовʼязкові ворота дії назовні** з фіксацією в графі
   рішень (не «валідація взагалі» — Legora/Clearbrief уже продають перевірки).
4. **Український правовий контекст** — ніша порожня (LIGA360/VERDICTUM дають
   дані без агентів/графа/API).
5. **Синтонія-протоколи** (згода на кордоні, суверенність простору) — у світі
   навіть не сформульовано як задача.
6. **Правозахисна доказова база З метаболізмом** — Uwazi зберігає, Harvey
   аналізує, ніхто не зʼєднує. Прямий продукт для ЄСПЛ/масових позовів.
